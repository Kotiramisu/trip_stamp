# Trip Stamp


## 1. アプリ紹介

　Trip Stamp（トリスタ）は、旅行の計画から思い出の共有までをサポートする旅行プラン共有サービスです。
　旅行先や観光スポットを探すだけでなく、実際に旅行した人が作成したプランを参考にすることで、AIやガイドブックだけでは分からないリアルな体験や感想を知ることができます。
　また、自分が訪れた場所や旅行の思い出、役立った情報をプランとして投稿することで、ほかの旅行者の新しい発見や旅行計画に役立ててもらうことができます。

『　誰かの旅の足跡が　次の誰かの旅のきっかけに　』

Trip Stampは、旅行する人同士が実体験を共有し、新しい旅との出会いを生み出すサービスを目指します。


## 2. このアイデアはどこから生まれたか

　友人と旅行の計画を立てる際、行きたい観光スポットを探すことはできてもそれらをどのような順番で巡ればよいのか、どのくらいの時間や予算が必要なのかを調べるのに苦労した経験があった。参考になる旅行プランを探しても、個人ブログなどでは一つの旅行ルートを紹介しているものが多く、複数のプランを比較しながら、自分たちに合った旅行を考えるには、さまざまなサイトを行き来する必要があった。
　また、古い記事では、紹介されているお店が閉店していたり、観光施設が改装・休業中だったりと、現在の状況と情報が一致しないこともあります。記事の公開日だけではなく、実際に訪れた日付や投稿者の感想、注意点など、現地を訪れた人ならではの情報も旅行先を決めるうえで重要だと感じました。

　旅行に行って帰ってきた後でにここは抑えておいた方がいいというスポットを見逃していた時の後悔がでかかった。
　そこで、実際に旅行した人のプランや体験を一つの場所に集約し、複数の旅行プランを比較・参考にできるサービスがあれば、旅行の計画をよりスムーズに進められるのではないかと考えました。


## 3. 課題

### 3-1. 解決したい課題

- 行きたい場よを国立よくわまれるルートや予算を知る
- SNSやブログでは投稿者ごとに情報・条件が違うので比較したい
- 情報を自分で整理する必要があり時間と手間がかかる

### 3-2. 解決したい課題の本質

- 計画が面倒になり、行きたい場所を諦めたり、無難な旅行先になる

## 4. 想定ユーザー

### 4-1. 想定しているユーザー

年齢設定
- 年齢：20、30代の比較的若いユーザー
- 理由：旅行前の情報収集に積極的：SNSやWebで旅行先や口コミを調べる習慣がある。
　また体験を共有する文化があるため自分の旅行写真や感想を投稿し、ほかの人の参考にしてもらうことに抵抗が少ない。

生活状況
- 生活・状況：生活にはそんなにゆとりはないが、ある程度の経済力がついてきている状況
- 理由：旅行プランを比較。予算・移動時間・訪問順などを比較して、自分に合う旅を考えたい。

### 4-2. 自分とユーザーの距離

自分自身が友人との旅行を計画する際に経験した課題をきっかけに考案しました。
旅行先や行ってみたいスポットはSNSなどで見つけられる一方、それらを組み合わせた旅行プランを考える際には、Google Mapsで位置関係を調べたり、複数のSNS投稿やブログを見比べたりする必要があり、情報収集や比較に手間がかかると感じていました。
そのため、まずは自分自身を最初の想定ユーザーとし、同じように友人やパートナーとの旅行を計画する身近な人を対象に、課題やニーズを検証したいと考えています。

### 4-3. 実際に使われる可能性について(需要・存在確認)

旅行先や観光スポットを探す際にはインスタグラムやTikTokなどのSNSを利用し、旅行計画を立てる際にはGoogle Mapsやブログ、ほかのSNS投稿などを組み合わせて情報収集することが考えられます。しかし、訪問スポットや移動手段、所要時間、予算などの情報は複数の投稿やWebサイトに分散しているため、自分に合った旅行プランを見つけるには、それぞれの情報を確認して比較する必要があります。
そこで本アプリで旅行日数や予算などの条件から検索し、複数のプランを比較して手間を減らすのに使用してもらうことを目指します。

## 4-4. ユーザーがサービスを導入して利用するまでのイメージ(導入・継続の流れ)

SNS等で気になる観光スポットを見つけ旅行に行きたいと考えます。
トリップスタンプにアクセスし都道府県を選択、旅行日数、予算気になるテーマなどの条件を指定し検索します。
その後実際に旅行した人のプランを確認して比較し、自分にあったプランを見つけ参考にします。
参考にしたプランをもとに自分の旅行先、訪問順何度を考え計画を立てます。
最後に自分のプランを入力し、感想やアドバイスを投稿します。
そして次の旅行でもトリップスタンプを利用し他のユーザーのプランを参考にします。

## 5. 既存サービス・競合調査

### 5-1. 競合サービス

- サービス名：生成AI全般
- どんなことができるか：旅行計画を全て網羅してくれる。
何を聞いてもネットの情報を集約して利用者の期待に応えてくれる。

- サービス名：インスタグラムやTikTok
- 行きたくなるような観光スポットなどの情報を取得し、タグ検索等でその周辺の情報を取得することができる。

- サービス名：Google Map
- 行きたいスポットなどで検索をかけて、その周辺の情報を取得できる。
また口コミで生の声を聞くこともできる。

- サービス名: 個人ブログ等
- 周辺情報やモデルコースなどを細かく書いている。


### 5-2. 足りない機能、課題

- 投稿者の経験や生の声を聞ける点はAIでは得られない。またAIでは情報の正確性を測れず、また自分で情報を個別で検索しなければいけない。
- インスタグラムやTikTokでは１スポットの情報を得るのには十分だが、旅行プラン全体を紹介している投稿等では条件も違い、１つ１つ比較し検討するには手間がかかる。
- 個人ブログでも紹介しているコースは多くても２つで、条件や予算も違い、他のプランと比較するとなると手間がかかる。


### 5-3. 差別化を「体験価値」で表現する

- 私のアプリの差別化ポイント：このアプリではなんとなく旅行に行きたいけど、全体のプランを考えるのが面倒なひとが移動手段、日数、金額などの情報で絞り、比較して自分のプランに落とし込むことができる。
- 実際に旅行をしておすすめだった点、反省点や注意点など生の声を聞くことができる。

### アプリの使い方

### 1. 日本地図から旅行先を探す
トップページには日本地図を表示し、気になる都道府県を選択することで、その地域の観光スポットや旅行プランを探すことができます。

### 2. 地図から観光スポットを探す　（本リリースで実装）
選択した都道府県の地図上に観光スポットをピンで表示します。テーマタグを選択することで、神社・寺、自然、グルメなど、興味のあるジャンルからスポットを探すことができます。

### 3. 旅行プランを検索・比較する
地域やカテゴリー、旅行日数、予算などの条件から旅行プランを検索できます。実際に旅行したユーザーの投稿を参考に、訪問先や旅行内容を比較できます。
MVPリリースでは地域を選択後にテーマタグ、予算で条件を絞り、一覧で旅行プランを比較します。

### 4. 旅行プランの詳細を確認する
旅行プランの詳細画面では、訪問したスポットを地図上にピンで表示します。訪問順や滞在時間、移動手段、予算に加え、投稿者の感想やアドバイスを確認できます。

### 5. 自分の旅行プランを投稿する
実際に訪れたスポットや訪問順、滞在時間、予算、旅行の感想やアドバイスなどを登録し、自分の旅行経験をほかのユーザーと共有できます。


## 8. このアプリの懸念点とその対策

### 懸念点

- 投稿が集まらない
- グーグルマップで満足してしまうかもしれない。また投稿するメリットがない。

### 解決策
- 家族や友人に協力してもらいリリース前に投稿数を確保する
- UIを見やすく、プランの比較しやすくする。
- 投稿簡単にできるようにする
- 本リリース後は投稿者が満足するようないいねっだったり、フォロー機能をつける。

### 10-2. 技術選定の比較検討

Render、Neonは現在もミニアプリで採用していて、無料プランに期限がない。GitHubと連携したデプロイができる。

地図・スポット検索：Google Maps Platformは最初はなるべく卒制ということで無料でできるものということで、当初はOpenStreetMapを利用する案も検討したが、スポット検索の利便性や情報の充実度を重視してGoogle Maps Platformを採用する方針に変更した。
Googleから取得した情報の保存には利用規約上の制限があるため、Place IDを中心に管理し、その他の情報は保存可能な条件を確認して扱う。

卒制で初めてのAPI利用になるのでしっかりと上限を設定して、無料枠で抑えられるような設定をして予想外の請求がこないよう注意する。
