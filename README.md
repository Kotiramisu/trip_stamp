## 1. アプリ紹介

　Trip Stamp（トリスタ）は、旅行の計画から思い出の共有までをサポートする旅行プラン共有サービスです。
　旅行先や観光スポットを探すだけでなく、実際に旅行した人が作成したプランを参考にすることで、AIやガイドブックだけでは分からないリアルな体験や感想を知ることができます。
　また、自分が訪れた場所や旅行の思い出、役立った情報をプランとして投稿することで、ほかの旅行者の新しい発見や旅行計画に役立ててもらうことができます。

『　誰かの旅の足跡が　次の誰かの旅のきっかけに　』

Trip Stampは、旅行する人同士が実体験を共有し、新しい旅との出会いを生み出すサービスを目指します。


## 2. このアイデアはどこから生まれたか

　友人と旅行の計画を立てる際、行きたい観光スポットを探すことはできてもそれらをどのような順番で巡ればよいのか、どのくらいの時間や予算が必要なのかを調べるのに苦労した経験があった。参考になる旅行プランを探しても、個人ブログなどでは一つの旅行ルートを紹介しているものが多く、複数のプランを比較しながら、自分たちに合った旅行を考えるには、さまざまなサイトを行き来する必要があった。
　また、古い記事では、紹介されているお店が閉店していたり、観光施設が改装・休業中だったりと、現在の状況と情報が一致しないこともあります。記事の公開日だけではなく、実際に訪れた日付や投稿者の感想、注意点など、現地を訪れた人ならではの情報も旅行先を決めるうえで重要だと感じました。

　旅行に行って帰ってきた後でにここは抑えておいた方がいいというスポットを見逃していた時の後悔がでかかった。
　そこで、実際に旅行した人のプランや体験を一つの場所に集約し、複数の旅行プランを比較・参考にできるサービスがあれば、旅行の計画をよりスムーズに進められるのではないかと考えました。


## 3. 課題

### 3-1. 解決したい課題

- 旅行先でのルートや所要時間など予定の立て方の参考を比較が容易でない
- 情報をいろんなところから取らないといけない
- 比較したプランに生の声が載ってなく機械的

### 3-2. 解決したい課題の本質

・楽しいはずの旅行が情報収集でめんどくさくなる
・複数人で行くときに選択肢を用意しやすく、参考にしてどれがいいか選びやすい


## 4. 想定ユーザー

年齢設定
- 年齢：20、30代の比較的若いユーザー
- 理由：旅行前の情報収集に積極的：SNSやWebで旅行先や口コミを調べる習慣がある。
　また体験を共有する文化があるため自分の旅行写真や感想を投稿し、ほかの人の参考にしてもらうことに抵抗が少ない。

生活状況
- 生活・状況：生活にはそんなにゆとりはないが、ある程度の経済力がついてきている状況
- 理由：旅行プランを比較。予算・移動時間・訪問順などを比較して、自分に合う旅を考えたい。


## 5. 既存サービス・競合調査

### 5-1. 競合サービス

- サービス名：生成AI全般
- どんなことができるか：旅行計画を全て網羅してくれる。
何を聞いてもネットの情報を集約して利用者の期待に応えてくれる。

- サービス名：tabiori
- URL：https://tabiori.com/ja/
- どんなことができるか：旅行の予定を「しおり」としてまとめ、同行者と共有できる。旅程だけでなく、持ち物やメモ、写真など旅行に必要な情報を一か所に整理でき、グループ旅行の計画から旅行中の情報共有まで行える。

- サービス名：旅ばな
- URL：https://tabimae-jp.com/services/tabibana
- どんなことができるか：旅行の計画・共有・記録を一つにまとめた旅のしおりアプリです。行き先や日程だけでなく、地図、予約情報、予算、持ち物、写真まで一つの旅行にまとめ、同行者との共同編集にも対応しています。


### 5-2. 足りない機能、課題

- シンプルであるアプリほど使い辛さや、得られる情報が少なく、本当に欲しい情報が手に入らない
- 旅行後や当日に使うためのものが多いが、自分が作りたいのは旅行するまでの計画に焦点を当てたもので、その課題や良かった点をシェアするものであるため
- 投稿者の経験や生の声を聞ける点はAIでは得られない。またAIでは情報の正確性を測れず、また自分で情報を個別で検索しなければいけないため


### 5-3. 差別化を「体験価値」で表現する

- 私のアプリの差別化ポイント：このアプリではなんとなく旅行に行きたいけど、全体のプランを考えるのが面倒なひとが移動手段、日数、金額などの情報で絞り、比較して自分のプランに落とし込むことができる。
- 実際に旅行をしておすすめだった点、反省点や注意点など生の声を聞くことができる。


## 6. アプリの実装について

### MVPで作る機能

ログイン、ログアウト機能
旅行プランのCRUD

### 今後の追加機能

タグの検索、お気に入り、プロフィール、ランキング機能、記事紹介、いいね、フォロー機能

### アプリの使い方

### 1. 日本地図から旅行先を探す
トップページには日本地図を表示し、気になる都道府県を選択することで、その地域の観光スポットや旅行プランを探すことができます。

### 2. 地図から観光スポットを探す
選択した都道府県の地図上に観光スポットをピンで表示します。カテゴリーを選択することで、神社・寺、自然、グルメなど、興味のあるジャンルからスポットを探すことができます。

### 3. 旅行プランを検索・比較する
地域やカテゴリー、旅行日数、予算などの条件から旅行プランを検索できます。実際に旅行したユーザーの投稿を参考に、訪問先や旅行内容を比較できます。

### 4. 旅行プランの詳細を確認する
旅行プランの詳細画面では、訪問したスポットを地図上にピンで表示します。訪問順や滞在時間、移動手段、予算に加え、投稿者の感想やアドバイスを確認できます。

### 5. 自分の旅行プランを投稿する
実際に訪れたスポットや訪問順、滞在時間、予算、旅行の感想やアドバイスなどを登録し、自分の旅行経験をほかのユーザーと共有できます。


## 7. このアプリの懸念点とその対策

### 懸念点

- 投稿が集まらない
- グーグルマップで満足してしまうかもしれない。また投稿するメリットがない。

###　　解決策
- リリース前に投稿数を確保する
- UIを見やすく、プランの比較しやすくする。
- 投稿簡単にできるようにする
- 投稿者が満足するようないいねっだったり、フォロー機能をつける。

### 9-2. 技術選定の比較検討

- 他にどんな技術を候補にしたか
- なぜその候補ではなく、この技術を選んだのか
- 不採用にした技術とその理由

Render、Neonは現在もミニアプリで採用しているため、使いやすので採用。

地図・スポット検索：Google Maps Platformは最初はなるべく卒制ということで無料でできるものということで、当初はOpenStreetMapを利用する案も検討したが、スポット検索の利便性や情報の充実度を重視してGoogle Maps Platformを採用する方針に変更した。
Googleから取得した情報の保存には利用規約上の制限があるため、Place IDを中心に管理し、その他の情報は保存可能な条件を確認して扱う。

卒制で初めてのAPI利用になるのでしっかりと上限を設定して、無料枠で抑えられるような設定をして予想外の請求がこないよう注意する。
